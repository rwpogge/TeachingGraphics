# Exoplanet Properties

Plot exoplanet properties.

We try to make these self-updating by using `astroquery` to retrieve data from the [NASA Exoplanet Archive](https://exoplanetarchive.ipac.caltech.edu/), and
include files for selected solar system bodies and main sequence stars that won't update frequently (if at all)

## Notebooks

 * `aM_exoplanets.ipynb` - Mass vs. semimajor axis for all confirmed exoplanets to date
 * `rvHistory.ipynb` - plots of RV semi-amplitude and planet mass vs. discovery year for confirmed RV exoplanets
 * `MassRadius_SSExoStars.ipynb` - Mass-radius relation plot following Chen & Kipping [2017, ApJ, 834, 17](https://ui.adsabs.harvard.edu/abs/2017ApJ...834...17C), Figure 3
